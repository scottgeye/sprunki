# Sprunkified Beatbox Lab (Web)

A heavily inspired browser loop-mixer with original project-made UI/audio.

## Features

- Drag-and-drop characters into 8 stage slots
- Play / Pause / Stop transport
- Random mix button
- Tempo slider (72–140 BPM)
- Scene switcher (Neon / Sunset / Void) that changes visual mood and pitch profile
- Combo detection banner for specific cast combinations
- Procedural Web Audio synthesis (no external sample packs)

## Run locally

```bash
python3 -m http.server 8080
```

Open: `http://localhost:8080`

## Notes

- Art and sound are generated in this repository.
- This is inspired by the drag-and-drop beatbox format while remaining an original implementation.
